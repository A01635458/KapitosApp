2.1 ANÁLISIS
------------------------------------------------------------------------------

CBL (CHALLENGE-BASED LEARNING) ACTUALIZADO
-------------------------------------------

BIG IDEA: Conexión Directa entre Productores y Consumidores de Café

ESSENTIAL QUESTION: 
¿Cómo podemos empoderar a los pequeños productores de café mexicanos para que 
alcancen mercados directos mientras garantizamos a los consumidores café de 
calidad con trazabilidad real?

CHALLENGE:
Desarrollar una aplicación móvil que conecte directamente a productores de café 
con consumidores finales, utilizando Machine Learning para personalizar 
recomendaciones y garantizar la calidad a través de certificaciones verificadas.

GUIDING QUESTIONS:
1. ¿Cómo pueden los productores pequeños competir sin intermediarios?
2. ¿Qué información necesitan los consumidores para confiar en un productor?
3. ¿Cómo puede la tecnología validar la calidad del café?
4. ¿Qué barreras enfrentan los productores para digitalizar su negocio?

GUIDING ACTIVITIES:
- Entrevistas con productores de café en Veracruz y Chiapas
- Análisis de plataformas existentes de comercio directo
- Pruebas de usuario con consumidores de café de especialidad
- Investigación de estándares de certificación (Orgánico, Comercio Justo)

SOLUTION:
KapitosApp - "La Ruta del Café": Plataforma móvil iOS que:
- Permite registro y validación de productores
- Conecta consumidores con productores certificados
- Usa ML para recomendaciones personalizadas basadas en preferencias
- Clasifica tipos de café usando visión por computadora (CoreML)
- Proporciona mensajería directa cliente-productor
- Visualiza productores en mapa interactivo

REQUERIMIENTOS FUNCIONALES
--------------------------

RF-001: El sistema debe permitir registro de usuarios con email y contraseña
RF-002: El sistema debe capturar preferencias de café (procesos, tuestes, bebidas, etc.)
RF-003: El sistema debe autenticar usuarios con Supabase Auth
RF-004: El sistema debe permitir registro de productores con información de finca
RF-005: El sistema debe validar y aprobar productores por administradores
RF-006: El sistema debe mostrar dashboard administrativo con métricas
RF-007: El sistema debe generar recomendaciones personalizadas usando ML
RF-008: El sistema debe permitir mensajería entre clientes y productores
RF-009: El sistema debe mostrar mapa interactivo de productores
RF-010: El sistema debe clasificar tipos de café usando CoreML
RF-011: El sistema debe enviar notificaciones contextuales inteligentes
RF-012: El sistema debe permitir a productores gestionar su tienda virtual
RF-013: El sistema debe soportar temas claro y oscuro
RF-014: El sistema debe validar datos de formularios en tiempo real
RF-015: El sistema debe mantener historial de conversaciones

REQUERIMIENTOS NO FUNCIONALES
-----------------------------

RNF-001: RENDIMIENTO
- Tiempo de carga de vistas < 2 segundos
- Recomendaciones generadas en < 5 segundos
- Clasificación de imágenes < 1 segundo

RNF-002: SEGURIDAD
- Autenticación mediante Supabase Auth con JWT
- Row Level Security (RLS) en todas las tablas
- Contraseñas con mínimo 6 caracteres
- Encriptación de datos en tránsito (HTTPS)

RNF-003: USABILIDAD
- UI consistente con Human Interface Guidelines de Apple
- Soporte para VoiceOver (accesibilidad)
- Feedback visual en todas las acciones
- Mensajes de error claros y descriptivos

RNF-004: DISPONIBILIDAD
- API disponible 99.5% del tiempo
- Base de datos en Supabase con backups automáticos

RNF-005: COMPATIBILIDAD
- iOS 17.0 o superior
- iPhone y iPad
- Xcode 15.0 o superior para desarrollo

RNF-006: ESCALABILIDAD
- Arquitectura basada en servicios independientes
- Base de datos PostgreSQL escalable
- Soporte para miles de usuarios concurrentes

ALINEACIÓN PROBLEMÁTICA / SOLUCIÓN / IMPACTO

PROBLEMÁTICA:
Los pequeños productores de café en México carecen de:
- Canales directos para llegar a consumidores finales
- Plataformas que certifiquen y promuevan su trabajo
- Visibilidad en el mercado digital
- Márgenes de ganancia justos (pierden ante intermediarios)

Los consumidores enfrentan:
- Desconfianza sobre el origen real del café
- Falta de trazabilidad del producto
- Sobreprecios por cadenas de distribución largas
- Desconocimiento del proceso de producción

SOLUCIÓN:
KapitosApp conecta directamente a ambas partes mediante:
- Registro verificado de productores con certificaciones
- Sistema de recomendaciones personalizadas con IA
- Mensajería directa sin intermediarios
- Mapa interactivo para descubrir productores
- Clasificador de café para educación y validación

IMPACTO:
Para Productores:
Visibilidad directa ante consumidores (literalmente "en el mapa")
Validación de su trabajo mediante certificaciones
Acceso a nuevos canales de venta sin intermediarios
Mejor margen de ganancia
Herramientas para gestionar su negocio digital

Para Consumidores:
Café con trazabilidad real y verificada
Apoyo directo a caficultores mexicanos
Recomendaciones personalizadas según sus gustos
Conocimiento del origen y proceso de su café
Conexión directa con quien produce su café

Impacto Social:
Fortalecimiento de la economía rural
Preservación de técnicas tradicionales de cultivo
Promoción del café de especialidad mexicano
Educación sobre producción de café sostenible

POLÍTICAS RLS (ROW LEVEL SECURITY)
----------------------------------

-- Usuarios pueden leer su propio perfil
CREATE POLICY "Users can read own profile" ON profiles
  FOR SELECT USING (auth.uid() = id);

-- Usuarios pueden leer productores aprobados
CREATE POLICY "Anyone can read approved producers" ON producers
  FOR SELECT USING (status = 'approved');

-- Solo admins pueden aprobar productores
CREATE POLICY "Admins can update producer status" ON producers
  FOR UPDATE USING (
    EXISTS (
      SELECT 1 FROM profiles 
      WHERE id = auth.uid() AND role = 'admin'
    )
  );

-- Usuarios pueden leer sus propias conversaciones
CREATE POLICY "Users can read own conversations" ON conversations
  FOR SELECT USING (
    auth.uid() = client_id OR auth.uid() = producer_id
  );
